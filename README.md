# Python Smart Task Manager

A command-line task management application built using Python, Object-Oriented Programming, and SQLite.

The application allows users to create and view tasks while storing task information in a database.

## Features

- Add new tasks
- View saved tasks
- Set task priorities: Low, Medium, or High
- Set task deadlines
- Store tasks permanently using SQLite
- Validate task titles and priorities

## Technologies Used

- Python
- SQLite
- sqlite3
- Object-Oriented Programming (OOP)
- SQL
- Exception handling and input validation
